# 💼 QG de Compra e Venda - Arbitragem & Facebook Marketplace

Este projeto é uma central operacional para o gerenciamento de compra com cupons/descontos e revenda de produtos físicos no Facebook Marketplace e grupos locais.

Projetado para ser aberto diretamente como um **Vault do Obsidian** ou gerenciado via Markdown.

---

## 📂 Estrutura de Pastas

* **`00_Radar_Compras/`**: Produtos garimpados e comprados com cupom, aguardando entrega e rastreio.
* **`01_Estoque_Pronto/`**: Produtos em mãos, conferidos e com fotos tiradas, prontos para anunciar.
* **`02_Briques_Ativos/`**: Anúncios que estão no ar no Marketplace e grupos da região.
* **`03_Para_Repostar/`**: Anúncios que completaram mais de 7 dias ou perderam tração, precisando de repost/renovação.
* **`04_Vendidos_Lucro/`**: Histórico de briques finalizados, com cálculo do lucro líquido e ROI real.
* **`05_Clientes_CRM/`**: Fichas de compradores e contatos de clientes frequentes.
* **`_Templates/`**: Modelos prontos para criar novos briques, anúncios e clientes.
* **`_Painel/`**: Dashboard geral com métricas e consultas Dataview.
* **`_legado_mago/`**: Arquivos, scripts e assets do projeto anterior arquivados com segurança.

---

## 🚀 Como Usar no Obsidian

1. Abra o **Obsidian**.
2. Clique em **"Open folder as vault"** (Abrir pasta como cofre).
3. Selecione esta pasta (`magodaultilidade`).
4. (Recomendado) Instale os plugins comunitários **Templates** (ou Templater), **Dataview** e **Kanban**.
5. Consulte o arquivo `_Painel/Dashboard - Visão Geral.md` para começar.
